# Rewind

Lightweight optimized clipping software called Rewind.

Rewind saves the last few seconds of your game when you press a shortcut. It runs in the tray, keeps your clips on your PC, and uses your GPU for recording when it can.

## Download

Get **Rewind-Setup.exe** from [Releases](https://github.com/rejzormax/Rewind/releases/latest). Run setup, open Rewind, then click **Start buffer**. The first install needs an internet connection to get the recording files.

Press **Ctrl + Shift + F9** to save a clip. You can choose 15, 30, 60 or 120 seconds in settings. Clips go to **Videos/Rewind** unless you pick another folder
